## Features

- Dashboard with admission statistics
- Student registration
- Multi-step admission application form
- Application listing with search and filters
- Application details and status management
- Document upload simulation
- Application review and approval/rejection
- Entrance exam score management
- Merit list generation
- Fee management
- Admission confirmation
- Login and registration interface
- Responsive design for desktop and mobile
- Dark mode

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- GitHub Pages
